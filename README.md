# Тайный круг

Адаптивный многостраничный сайт клуба игры в мафию в Москве.

## Стек

HTML, Bootstrap 5.3.8, CSS и небольшой JavaScript без сторонних библиотек и сборки.
Для просмотра откройте index.html в браузере. Для Bootstrap CDN, шрифта и карты нужен интернет. Фотографии хранятся локально.

## Страницы

- index.html — главная, форматы игры, ближайшие вечера, фотографии, программа, расчёт стоимости и вопросы.
- schedule.html — игры по датам, формы записи, отзывы участников и форма отзыва.
- rules.html — роли, этапы, условия победы и регламент.
- reviews.html — переход к разделу отзывов на странице игр.
- contacts.html — информация о клубе, контакты, часы работы и карта.
- css/custom.css — палитра, размеры изображений, состояния и анимации.
- js/custom.js — расчёт стоимости, просмотр фотографий и появление блоков.
- images/credits.md — источники дополнительных фотографий.
- images/generation-prompts.md — запросы для серии изображений клуба.

## Компоненты Bootstrap

Navbar, Grid, Cards, Tabs, Carousel, Accordion, Modal, Offcanvas, формы и кнопки. Шесть фотографий клуба объединены в одну карусель с возможностью открыть снимок крупнее. На странице контактов описание клуба расположено перед картой. Все страницы используют одинаковый Bootstrap Container и заголовки display-4. Новые блоки используют стандартные классы сетки, отступов, цветов и типографики Bootstrap.

## Формы и данные

Обязательные поля проверяет браузер. Формы используют GET-переход на ту же страницу. Серверный обработчик и платёжная система отсутствуют. Расписание, тарифы и доступность мест заданы в HTML. Расчёт стоимости использует тариф ближайшей игры: 1 200 ₽ за человека.

Анимации учитывают prefers-reduced-motion. Без JavaScript содержимое остаётся доступным, стоимость можно рассчитать по указанному тарифу.

Главная открывается короткой заставкой с закатом и появлением текста один раз за сеанс вкладки (sessionStorage). При обновлении и возвращении на главную заставка пропускается. При запросе уменьшения движения она также пропускается. Шрифт — Golos Text с кириллицей; красный акцент используется в кнопках, навигации и блоке расчёта. Серия из шести изображений клуба создана специально для сайта встроенным ImageGen.

На странице правил — шесть отдельных карточек ролей с иллюстрациями: мирный житель, мафия, дон, комиссар, доктор и маньяк. При открытии пункта Bootstrap Accordion показывает изображение, краткую цель, дневные и ночные действия и один совет. Дополнительный JavaScript для переключения не нужен. Во всех подвалах используется логотип клуба.
