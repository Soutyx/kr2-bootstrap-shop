# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию адаптивного многостраничного сайта клуба игры «Мафия» — «Тайный круг», разработанную с использованием Bootstrap.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы с названием клуба;
- Bootstrap-навигация;
- hero-блок с масками и кнопкой записи;
- информация о клубе;
- карточки ближайших игр;
- фотогалерея;
- контакты и обзорная карта Москвы;
- подвал страницы.

## Используемые технологии

- HTML;
- Bootstrap 5.3.8 (CSS и JS Bundle);
- CSS;
- Git;
- GitHub.

React, сборщик, дополнительные библиотеки и собственный JavaScript не используются. Для просмотра сайта достаточно открыть `index.html` в браузере. Для загрузки Bootstrap через CDN и карты требуется интернет.

## Практическая работа 10

Тема: «Страница на Bootstrap: компоненты».

Выполнено:

- добавлена единая Bootstrap-навигация на всех четырёх страницах с выделением текущей страницы;
- создана главная страница `index.html`: hero-блок, информация о клубе, Carousel, карточки ближайших игр и контакты;
- создана страница `reviews.html`: Cards с учебными отзывами, форма и Modal для подтверждения;
- создана страница `rules.html`: правила клуба, описание игры, Accordion с ролями и этапами, условия победы и таблица баллов;
- создана страница `schedule.html`: карточки игр, Tabs для выбора даты и Modal с формой записи на выбранную игру;
- использованы компоненты `navbar`, `card`, `btn`, `badge`, `alert`, `carousel`, `modal`, `form-control`, `form-select`, `form-check`, `accordion`, `nav-pills`;
- добавлен файл `css/custom.css` для оформления в тёмной гамме с красными и золотыми акцентами;
- добавлена адаптация для мобильных устройств;
- добавлены лёгкие CSS-анимации появления блоков, движения масок и наведения на карточки и кнопки;
- расширена форма записи: фамилия, имя, отчество, почта, телефон, количество игроков, опыт и комментарий;
- добавлены обязательное согласие на обработку персональных данных и необязательная подписка на рассылку;
- проект подготовлен к сдаче контрольной работы №2.

Формы демонстрационные: обязательные поля проверяет браузер, после подтверждения показывается учебное сообщение. Данные не сохраняются, отзывы не публикуются, реальные места не бронируются. Формы используют GET-переход на ту же страницу, поэтому следует вводить только вымышленные данные. Расписание и количество свободных мест заданы в HTML.

## Структура проекта

- `index.html` — главная страница;
- `reviews.html` — отзывы и форма отправки отзыва;
- `rules.html` — правила клуба и игры;
- `schedule.html` — расписание и формы записи;
- `css/custom.css` — дополнительные стили проекта;
- `images/` — изображения проекта;
- `README.md` — описание проекта.
